# Paper figures and tests

Run from this folder (`py <script>.py` on Windows, `python <script>.py` elsewhere).
Scripts that need data read `../results/table_S1_per_dataset.csv`; copy it next to the script
or adjust the path at the top of the script.

| Script | Output |
|---|---|
| `fig1_motivation.py` | Fig. 1 |
| `fig2_framework.py` | Fig. 2 |
| `fig3_reduction_quality.py` | Fig. 3 (needs `table4_per_dataset.csv`, i.e. Table S1) |
| `fig4_case_gse20711.py` | Fig. 4 |
| `paired_tests.py` | Paired Wilcoxon tests (DT vs RF, 12 datasets) |
