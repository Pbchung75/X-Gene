# X-Gene: A Rule-Centric Framework for Explainable Gene Expression Classification

*X-Gene: A Rule-Centric Framework for Explainable Gene Expression Classification
and Biological Interpretation* (ICCIES 2026).

X-Gene extracts IF–THEN rules from decision trees and random forests trained on microarray data,
keeps the original probe identifiers and thresholds, refines the rules on training data only,
evaluates the frozen rule set on held-out samples (coverage, confidence, source-model fidelity),
and links rule conditions to genes and Gene Ontology annotations.

## Installation
```bash
uv sync                 # or: pip install -e .
```
Python 3.12. Library versions are pinned in `uv.lock`.

## Data
The 12 datasets are public (GEO and CuMiDa) and are **not** stored in this repository.
See [`data/README.md`](data/README.md) for accessions and download steps.

## Reproducing the paper
Run the notebooks in this order:

| Step | Notebook | Produces |
|---|---|---|
| 1 | `notebooks/00.a_Format_GEO_Datasets.ipynb` | Processed GEO datasets |
| 2 | `notebooks/00.b_Format_Cumida_Datasets.ipynb` | Processed CuMiDa datasets (Table 1) |
| 3 | `notebooks/02_Benchmark.ipynb` | Predictive benchmark (Table 2) |
| 4 | `notebooks/04_Rule_Extraction_Holdout.ipynb` | Rule extraction and held-out evaluation |
| 5 | `notebooks/rule_extraction_results_summary.ipynb` | Rule statistics and agreement (Table 3) |

All settings (splits, seeds, selectors, model and refinement parameters) are in `configs/`.
Figures and statistical tests are generated by the scripts in `paper/`, using the CSV files in `results/`.

| Paper item | Script / file |
|---|---|
| Fig. 1 | `paper/fig1_motivation.py` |
| Fig. 2 | `paper/fig2_framework.py` |
| Fig. 3 | `paper/fig3_reduction_quality.py` + `results/table_S1_per_dataset.csv` |
| Fig. 4 | `paper/fig4_case_gse20711.py` |
| Table S1 | `results/table_S1_per_dataset.csv` |
| Paired tests | `paper/paired_tests.py` |

## Repository layout
```
configs/     experiment configuration
src/         pipeline, feature selection, models, rule extraction and interpretation
notebooks/   entry points (run in the order above)
paper/       scripts for the figures and tests in the paper
results/     aggregated results reported in the paper
data/        dataset accessions and download instructions
docs/        developer documentation
```
