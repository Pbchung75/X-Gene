# Datasets

The study uses 12 public cancer microarray datasets (Table 1 of the paper).
Raw data are not redistributed here. Download them from the sources below and place them under `Dataset/`
(paths are configured in `configs/datasets.yaml` and `configs/dataset_origin.yaml`).
Then run `notebooks/00.a_Format_GEO_Datasets.ipynb` and `notebooks/00.b_Format_Cumida_Datasets.ipynb`.
